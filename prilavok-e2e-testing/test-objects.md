# Объекты тестирования и серые зоны

## Форма регистрации приложения «Прилавок»

### Объекты тестирования

| Название | Тип объекта |
|---|---|
| Кнопка (закрытие формы) | Кнопка |
| Имя | Поле |
| Номер телефона | Поле |
| Email | Поле |
| Пароль | Поле |
| Повторите пароль | Поле |
| Улица, номер дома, номер квартиры | Поле |
| Подъезд | Поле |
| Этаж | Поле |
| Домофон | Поле |
| Комментарий к заказу | Поле |
| Зарегистрироваться | Кнопка |
| Кнопка «Зарегистрироваться» активна / не активна | Состояние |
| Войти | Кнопка |
| Кнопка «Войти» активна / не активна | Состояние |
| Сообщение об ошибке | Сообщение |
| Всплывающее окно «Всё получилось!» | Сообщение |

### Вопросы и допущения

| Объект / раздел требований | Неясность | Вопрос | Допущение |
|---|---|---|---|
| Надпись «У вас уже есть аккаунт» и кнопка «Войти» | В требованиях и на макете внизу формы регистрации надпись и кнопка. На сайте отсутствуют | На сайте внизу формы регистрации должна быть надпись и кнопка? | На сайте есть надпись «У вас уже есть аккаунт» и кнопка «Войти» |
| Email | Обязательность полей на сайте, в фигме и требованиях разная | Email обязателен для заполнения? | Email обязателен для заполнения |
| Email | В требованиях не указано, где должна быть обязательная точка | Где в адресе почты обязательно должна стоять точка? | Точка обязательна в тексте справа после знака @ |
| Номер телефона | Обязательность полей на сайте, в фигме и требованиях разная | Номер телефона обязателен для ввода? | Номер телефона обязателен для заполнения |
| Поля регистрации | Очередность полей в фигме, на сайте и в требованиях разная | Какая очередность полей верная? | Очередность полей верная как в требованиях и на макете |
| Номер телефона | Уникальность номера телефона | Номер телефона должен быть уникальным? | Номер телефона должен быть уникальным |
| Email | Надпись в поле Email | С заглавной буквы или строчной? | Надпись с заглавной буквы |
| Email | Сообщение «Пользователь с таким e-mail уже существует» | Где выводится сообщение? | Сообщение выводится под полем Email |
| Повторите пароль | Сообщение «Пароли не совпадают» | Где выводится сообщение? | Сообщение выводится под полем «Повторите пароль» |
| Имя | Разрешены пробелы и дефисы, но нет ограничений на количество и позицию | Разрешено ли вводить два дефиса подряд или пробел в начале/конце? | Дефис и пробел разрешены только как одиночные разделители внутри текста |
| Адрес доставки | Нет проверки на осмысленность ввода | Пропустит ли форму адрес из спецсимволов? | Адрес должен содержать буквы и валидное название улицы/дома |
| Номер телефона | В требованиях не указано, обязателен ли знак + | Обязателен ли знак + при вводе телефона? | Знак + обязателен в начале номера телефона |
| Плейсхолдеры полей | Поведение плейсхолдеров при начале ввода | Должен ли плейсхолдер исчезать при фокусе? | Исчезает |

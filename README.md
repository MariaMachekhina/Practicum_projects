# Practicum_projects
# Сквозное ручное тестирование приложения «Прилавок»

## Описание

Выпускной проект по сквозному ручному тестированию веб-приложения «Прилавок» — формы регистрации и авторизации пользователя.

Тестирование проведено на трёх окружениях: десктопные браузеры (Chrome, Firefox) с разными разрешениями и мобильное окружение (Android-эмулятор).

## Цель

Проверить корректность работы форм регистрации и авторизации: UI, API и базу данных. Найти дефекты и сделать заключение о готовности продукта к релизу.

## Объект тестирования

- **UI:** форма регистрации, форма авторизации
- **API:** эндпоинты `POST /api/v1/users`, `POST /api/v1/users/login`
- **БД:** таблица `user_model` (PostgreSQL через DBeaver)

## Тип тестирования

- функциональное (UI)
- API-тестирование (Postman)
- тестирование базы данных (DBeaver)
- smoke-тестирование
- мобильное тестирование (Android Studio, эмулятор)

## Что выполнено

- **Анализ требований:** выделены объекты тестирования, составлены вопросы и допущения по макетам и требованиям
- **Тест-дизайн:** классы эквивалентности и граничные значения для всех полей форм (имя, телефон, email, пароль, адрес, комментарий)
- **Smoke-тестирование:** 7 проверок критического пути
- **Регрессионное тестирование:** проведено по чек-листам курса; результаты зафиксированы в баг-репортах
- **API-тестирование:** проверка эндпоинтов регистрации и авторизации через Postman
- **Тестирование БД:** проверка сохранения данных в PostgreSQL через DBeaver
- **Мобильное тестирование:** проведено по чек-листу курса на Android-эмуляторе; результаты зафиксированы в баг-репортах
- **Баг-репорты:** 68 дефектов с шагами воспроизведения, ожидаемым и фактическим результатом, скриншотами

## Инструменты

- **Postman** — API-тестирование
- **DBeaver** — работа с PostgreSQL
- **DevTools** — проверка запросов и ответов
- **Android Studio** — мобильное тестирование на эмуляторе
- **Figma** — работа с макетами
- **Swagger** — документация API

## Ключевые дефекты

- **БР37, БР38, БР45, БР46** — регистрация проходит при незаполненном поле «Номер телефона», данные сохраняются в БД (критический)
- **БР57, БР58** — форма регистрации перекрывается надписями главной страницы (критический)
- **БР65** — при повороте экрана приложение закрывается (блокирующий)
